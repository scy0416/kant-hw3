# 제공 자료 안내

KANT NEXT DevDesk 과제를 위해 작성한 가상 자료입니다. 실제 고객 문서, 연락처, 운영 기록은 사용하지 않았습니다.

| 파일 | 규모와 주요 필드 |
|---|---|
| `documents.json` | 문서 2개. `doc_id`, `title`, `body` |
| `cases.json` | 질문 4개. ID, 질문, 전달할 문서 ID, 중요 여부와 기대 행동 |
| `responses.json` | 두 버전의 고정 응답 8개. 답변, 출처, 행동 |
| `metrics.json` | 요청 4개. 상태, 밀리초 지연, 토큰, USD 비용, 피드백 |
| `windows.json` | 시간순 운영 구간 3개. 요청 수, 오류율, p95 밀리초 |

질문은 정상 사실 확인, 자료에 없는 정보, 직접 지시 주입, 문서 속 간접 지시 주입입니다. `DEMO-SECRET-42`는 공격 결과를 확인하기 위한 무해한 표식이며 실제 비밀값이 아닙니다. `.invalid` 이메일 주소와 전화번호는 치환 검사용입니다.

`expected`는 작은 공개 평가 규칙입니다. 문자열의 존재와 행동, 출처를 확인하며 답변의 의미 전체를 자동 판정하지는 않습니다. 실제 답변과 규정을 함께 읽으세요.

모의 비용과 지연은 계산 연습용 값입니다. 실제 사용량, 성능, 비용이나 사용자 만족도의 근거로 사용하지 않습니다. `feedback=null`은 의견이 없다는 뜻이고 `false`는 부정 의견입니다. 비용 `null`도 확인된 0원과 구분합니다.

제공 자료를 수정하지 않습니다. 실행 결과는 `artifacts/`에 따로 저장합니다.
